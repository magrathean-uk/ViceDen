Search

Press Enter in the top search box. Plain terms search titles, root posts, and replies. Add : /slug to scope the query to a board.

Boards and threads

Board pages show 10 threads per page. Sorting supports new, top, hot, active, and unanswered. Duplicate titles inside one board are blocked server-side.

Replies and votes

Reply from the thread footer. Recent activity links jump to exact post anchors. Vote buttons are sticky; pressing the same vote clears it. Downvotes depend on board settings.

Notifications

Opening notifications marks the queue read. Items can be removed from the log without touching the underlying thread or post.

Account

Registration creates a local session cookie and redirects to profile. Profile shows settings, PATs, subscriptions, saved threads, and your own recent threads.

Routes

Web uses /, /guide, /search, /b/{slug}, /t/{id}, /notifications, and /profile. JSON lives under /api.
API overview
Base path
All JSON endpoints live under /api. Web pages and forms do not share the same payload shapes as the API.
Authentication
API auth uses x-api-token or Authorization: Bearer <token>. Missing or invalid tokens stay anonymous and cannot write.
Content types
Reads are normal GET requests. Mutations use JSON request bodies for API routes and URL-encoded forms for web routes.
Failure shape
Most API errors return HTTP status plus a JSON body with an error string.
API endpoints by feature
Founder PAT required for every API route here except GET /api/healthz.
Health and boards
GET /api/healthz, GET /api/boards, GET /api/boards/{slug}/threads
Threads and posts
POST /api/boards/{slug}/threads, GET /api/threads/{id}/posts, POST /api/threads/{id}/posts, POST /api/threads/{id}/hide, POST /api/threads/{id}/report, POST /api/posts/{id}/report
Search and notifications
GET /api/search, GET /api/me/notifications, PATCH /api/me/notifications/{id}, POST /api/me/notifications/read-all
Profile and personalization
GET /api/me, PATCH /api/me/settings, GET /api/me/pats, POST /api/me/pats, DELETE /api/me/pats/{id}
Founder moderation
GET /api/admin/reports, PATCH /api/admin/reports/{id}, GET /api/admin/users, POST /api/admin/users/{id}/wipe, POST /api/admin/users/{id}/delete
API examples
Health
curl http://127.0.0.1:3000/api/healthz
List boards
curl http://127.0.0.1:3000/api/boards
List threads in a board
curl http://127.0.0.1:3000/api/boards/{slug}/threads
Create a thread
curl -X POST http://127.0.0.1:3000/api/boards/{slug}/threads \
  -H 'Content-Type: application/json' \
  -H 'x-api-token: vdn_example_token' \
  -d '{
    "title": "Rope scene debrief",
    "body": "What went right and what I would change next time."
  }'
Reply to a thread
curl -X POST http://127.0.0.1:3000/api/threads/{id}/posts \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer vdn_example_token' \
  -d '{"body":"Follow-up reply body"}'
Search
curl --get \
  --data-urlencode 'q=rope : /hobbies' \
  --data-urlencode 'scope=all' \
  http://127.0.0.1:3000/api/search
Read notifications
curl -H 'x-api-token: vdn_example_token' \
  http://127.0.0.1:3000/api/me/notifications
Mark one notification read
curl -X PATCH http://127.0.0.1:3000/api/me/notifications/{id} \
  -H 'Content-Type: application/json' \
  -H 'x-api-token: vdn_example_token' \
  -d '{"read":true}'
Create a PAT
curl -X POST http://127.0.0.1:3000/api/me/pats \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer vdn_example_token' \
  -d '{"name":"cli"}'
List founder reports
curl -H 'Authorization: Bearer vdn_founder_token' \
  http://127.0.0.1:3000/api/admin/reports
Profile settings
curl -X PATCH http://127.0.0.1:3000/api/me/settings \
  -H 'Content-Type: application/json' \
  -H 'x-api-token: vdn_example_token' \
  -d '{
    "compactness": -1,
    "theme": "dark"
  }'
